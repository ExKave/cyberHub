Bluetooth Phonebook Extractor

Step-by-step guide to pair your Android device and extract contacts to a clean CSV on Fedora Linux.

1

Install Dependencies

Install the required Python D-Bus bindings and core BlueZ package:

sudo dnf install bluez python3-dbus
2

Pair Your Android Phone

Use the desktop interface or the terminal utility to pair your device:

Option A: Graphical Interface (Recommended)
  1. Open Settings → Bluetooth on your Fedora desktop.
  2. Ensure Bluetooth is turned ON and your phone is discoverable.
  3. Click your phone's name in the list to pair and confirm the PIN code on both devices.
CRITICAL PERMISSION PROMPT: When pairing completes on your Android screen, check the box labeled "Allow access to your contacts and call logs" and tap Allow.
Option B: Command Line Interface 
bluetoothctl
power on
scan on
# Replace with your actual phone MAC address
pair 54:9A:8F:95:28:20
trust 54:9A:8F:95:28:20
exit
3

Create the Extraction Script

Write the extraction script to your working folder (update DEVICE_MAC with your phone's address):

cat << 'EOF' > get_contacts.py
import sys, os, time, csv, dbus

DEVICE_MAC = "54:9A:8F:95:28:20"
TARGET_VCF = os.path.abspath("contacts_backup.vcf")
TARGET_CSV = os.path.abspath("contacts_backup.csv")

def extract_contacts():
    bus = dbus.SessionBus()
    try:
        obex = bus.get_object("org.bluez.obex", "/org/bluez/obex")
        client = dbus.Interface(obex, "org.bluez.obex.Client1")

        print(f"[*] Connecting to {DEVICE_MAC} via PBAP...")
        session_path = client.CreateSession(DEVICE_MAC, {"Target": "pbap"})

        session_obj = bus.get_object("org.bluez.obex", session_path)
        pbap = dbus.Interface(session_obj, "org.bluez.obex.PhonebookAccess1")

        pbap.Select("int", "pb")
        print("[*] Requesting contact file transfer...")
        pbap.PullAll(TARGET_VCF, "")
        time.sleep(2)

        resolved_path = None
        if os.path.exists(TARGET_VCF) and os.path.getsize(TARGET_VCF) > 0:
            resolved_path = TARGET_VCF
        else:
            fallback = os.path.expanduser("~/.cache/obexd/contacts_backup.vcf")
            if os.path.exists(fallback) and os.path.getsize(fallback) > 0:
                resolved_path = fallback

        if not resolved_path:
            print("[-] Error: No phonebook data received.")
            print("-> Check that 'Contact Sharing' is permitted in your phone's Bluetooth settings.")
            return

        print(f"[+] Downloaded vCard ({os.path.getsize(resolved_path)} bytes)")

        contacts = []
        name = "Unknown"
        with open(resolved_path, "r", encoding="utf-8", errors="ignore") as f:
            for line in f:
                line = line.strip()
                if line.startswith("FN:"):
                    name = line.replace("FN:", "").strip()
                elif line.startswith("TEL;") or line.startswith("TEL:"):
                    num = line.split(":")[-1].strip()
                    contacts.append({"Name": name, "Phone": num})
                    name = "Unknown"

        if contacts:
            with open(TARGET_CSV, "w", newline="", encoding="utf-8") as csvfile:
                writer = csv.DictWriter(csvfile, fieldnames=["Name", "Phone"])
                writer.writeheader()
                writer.writerows(contacts)
            print(f"[+] Exported {len(contacts)} contacts to: {TARGET_CSV}")
        else:
            print("[-] No contact entries could be parsed.")

    except Exception as err:
        print(f"[-] Bluetooth Error: {err}")

if __name__ == "__main__":
    extract_contacts()
EOF
4

Run Script & Verify Contacts

Unlock your phone screen and execute the script:

python3 get_contacts.py

Inspect the generated CSV output:

head -n 10 contacts_backup.csv
